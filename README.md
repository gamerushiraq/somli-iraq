# سوملي العراق | SOMLI Iraq

**الموقع المنشور:** https://gamerushiraq.github.io/somli-iraq/  
**السوق:** https://gamerushiraq.github.io/somli-iraq/market.html  
**مقارنة العروض:** https://gamerushiraq.github.io/somli-iraq/offers.html

سوملي منصة عراقية لعرض المنتجات وطلب الأسعار ومقارنة عروض المحلات، إضافة إلى سوق بيع وشراء بين المستخدمين.

## المزايا الحالية

- واجهة عربية RTL متجاوبة مع الموبايل.
- طلب أسعار مع المحافظة ورقم التواصل وتفاصيل الطلب.
- حسابات مستخدمين عبر Supabase Auth.
- تسجيل المحلات وطلبات اعتماد البائعين.
- لوحة المحل لإدارة المنتجات وطلبات الأسعار والاشتراكات.
- لوحة إدارة لمراجعة طلبات البائعين والمنتجات والإعلانات والمدفوعات.
- سوق بإعلانات وصور وأسعار ومحافظات وحالة المنتج.
- بحث وفلاتر حسب الفئة والمحافظة والسعر والحالة وتوفر الصور، وترتيب حسب السعر أو التاريخ.
- حفظ الإعلانات محلياً على الجهاز، ومشاركة روابط الإعلانات ونتائج البحث.
- مقارنة حتى 3 إعلانات جنباً إلى جنب.
- طلب ترويج مدفوع لا يتفعّل إلا بعد مراجعة الإدارة.

## النشر

المستودع يُنشر على GitHub Pages من فرع `main` بواسطة `.github/workflows/pages.yml`. فحوصات الجودة في `.github/workflows/quality.yml` تتحقق من صياغة ملفات JavaScript والملفات المحلية المرتبطة بالصفحات.

## قاعدة البيانات والأمان

المشروع الحي مرتبط بمشروع Supabase باسم **Somli Iraq**. مخطط قاعدة البيانات الفعلي لا يطابق المسودة القديمة في `schema.sql`.

- **لا تشغّل `schema.sql` على المشروع الحي.** الملف مسودة قديمة محفوظة لأغراض تاريخية فقط.
- تغييرات دوال الإدارة المميزة الصلاحيات موثقة في `database/secure-admin-rpc.sql`، وتحسين سياسات RLS موثق في `database/rls-policy-consolidation.sql`؛ وقد طُبّقت التغييرات على قاعدة البيانات.
- جداول البيانات العامة يجب أن تبقى محمية بـ RLS وسياسات دقيقة.
- المفتاح الموجود في الواجهة هو publishable key؛ لا تضع أبداً `service_role` أو أي مفتاح سري في ملفات GitHub Pages.
- موافقات الإعلانات والمحلات والمدفوعات يجب أن تبقى بيد الإدارة؛ لا يُنشر إعلان جديد مباشرةً عند الإرسال.
- حماية كلمات المرور المسرّبة ما زالت تحتاج إلى تفعيل يدوي من إعدادات Supabase Auth: [إعدادات أمان كلمات المرور](https://supabase.com/dashboard/project/vpducjdkjrbxeosdxvdi/auth/providers).

## حالة السوق وقت آخر تدقيق

كان هناك إعلان سوق واحد بحالة `pending` ولا توجد إعلانات معتمدة ظاهرة للعموم. لهذا قد يظهر السوق فارغاً إلى أن تُراجع الإدارة الإعلان. لم تُنشأ إعلانات تجريبية وهمية ولم تُغيّر حالة أي إعلان أثناء التدقيق.

## قواعد التشغيل الآمن

- لا حذف لجداول أو فهارس لمجرد ظهورها ضمن تقرير «غير مستخدمة».
- لا تعديل لبيانات العملاء أو طلبات الأسعار الحقيقية لغرض الاختبار.
- لا موافقة آلية على الإعلانات أو طلبات الدفع.
- اختبر التغييرات أولاً، واحتفظ برسالة commit واضحة لكل تعديل.
