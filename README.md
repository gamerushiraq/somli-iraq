# سوملي | Soumli

واجهة أولية عربية RTL لفكرة سوق عراقي لعرض المنتجات وطلب عروض الأسعار.

## الحالة الحالية
- واجهة متجاوبة للموبايل والكمبيوتر.
- بحث وفلاتر فئة ومحافظة.
- نموذج طلب سعر تجريبي.
- نموذج اهتمام للمحلات.
- بيانات منتجات **تجريبية وليست أسعاراً حقيقية**.
- الطلبات التجريبية تُحفظ في `localStorage` على نفس الجهاز فقط.
- لم يتم ربط Supabase أو تفعيل حسابات حقيقية أو إرسال طلبات للمحلات بعد.

## تشغيل محلي
افتح `index.html` بالمتصفح. ولتجربة أفضل، استخدم خادماً محلياً بسيطاً مثل VS Code Live Server.

## النشر على GitHub Pages
1. أنشئ مستودعاً عاماً باسم `soumli` في حساب GitHub.
2. ارفع جميع الملفات مع الحفاظ على مجلد `supabase`.
3. من Settings > Pages، اختر النشر من فرع `main` ومجلد `/(root)`.
4. انتظر حتى يظهر رابط النشر في صفحة Pages.

## ربط Supabase لاحقاً
1. أنشئ مشروعاً منفصلاً باسم Soumli على خطة Free بعد التأكد من خطة المؤسسة.
2. راجع `supabase/schema.sql` قبل تنفيذه في SQL Editor.
3. نضيف بعد ذلك مصادقة المستخدمين، ربط الواجهة بقاعدة البيانات، وسياسات صور Storage.
4. لا تضع `service_role` key في ملفات الواجهة العامة. المفتاح العام publishable/anon فقط يمكن استخدامه من الواجهة بعد ضبط RLS.

## التكلفة
يمكن تطوير واختبار النسخة الأولية باستخدام الخطط المجانية المتاحة. قد تتغير حدود الاستخدام أو سياسة إيقاف المشاريع غير النشطة؛ تحقق من لوحة الفوترة قبل إنشاء المشروع.
